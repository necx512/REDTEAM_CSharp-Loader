# REDTEAM_RedTeamNote
Pour ouvrir un projet vide dans vscode en C++, utiliser les projet qui ne sont pas tagué "UWquelquechose". "Projet vide" peut avoir ce tag et donc ne pas l'utiliser


Il faut publié la solution.
Souvent c'est le dll généré qui est interressant et pas l'exe qui est juste un loader je pense.
Un PE qui contient du code CLR a un header CLR.
le tool 'ildasm' permet de desassembler le code intermediaire. Si on lance l'exe il nous dira qu'il a pas de header CRL
